## 模型如何控制游戏

Colab 的 NVIDIA L4 训练了三个不同初始化的实体世界模型，每个更新 2200 次。训练数据共 91 场、136818 个完整观测，按整局分为 68 场训练和 23 场留出。这批数据含 53 场历史通关。模型根据骑士、在场螳螂、飞镖、地刺和实际按键预测接下来五个观测间隔。

三份教师对 12 种移动、跳跃和冲刺组合分别预测后果，再按模型之间的分歧给预测加权。学生 GRU 使用最近四次骑士和实体观测。蒸馏使用 55000 个训练窗口。游戏里，学生修正旧移动头的偏好，本地控制器根据碰撞、起跳和施法时序执行普通按键。挥刀、法术、聚集及紧急阴影冲刺均通过游戏原有输入实现。461092 次规划选择中，学生在相同输入下改变了 8775 次移动方案。

`teachers/` 保存三份 PyTorch 世界模型、各自的留出指标、门控蒸馏与均匀权重对照。游戏运行需要本目录的 `model.txt`、`head.weights` 和 `world.weights`。[训练配置和数据指纹](training.json) · [Colab 训练入口与数据格式](../../docs/adr/0018-sisters-object-world-distillation.md) · [第一目标对照模型](../sisters-tactics-v1/README.md)

## 本机运行

在已配置好的项目目录双击 [观看世界模型通关.vbs](../../观看世界模型通关.vbs)，即可观看一场。命令行也可以指定带有同版本 HKRLEnvMod 的游戏副本及战斗姐妹存档。下面使用项目本机训练副本和 3 号槽。应用会打开一个游戏窗口，打完后输出这次的逐场成绩路径。

```powershell
.\scripts\windows\play_sisters_tactics.ps1 -Checkpoint .\models\sisters-world-v2 -GameRoot .\runs\game-setup\collectors\5556 -Port 5556 -SaveSlot 3 -Episodes 1
```

评估使用的游戏插件源码版本是 `4d9951cdae3a6c5da412ba7e706842fcb805bc08`。模型及插件的 SHA-256 见 [frozen.json](frozen.json)。评估调用编号用于记录场次，Unity 自行产生战斗中的随机变化。
