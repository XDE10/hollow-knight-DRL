# 战斗姐妹回程飞镖候选

新策略在原速、原伤下取得 94/100 胜，0 场无伤。对照版取得 99/100 胜，7 场无伤。沿用 99 胜版作为默认演示，保留此版本和逐场记录供比较。

本轮 100 场共被飞镖打掉 152 格、被本体打掉 311 格、踩地刺掉 15 格。对照组分别为 170、121、0 格。每场均从第一只入场开始。无伤要求击败整个竞技场、所有观测的生命值一直为 9，并且没有受到伤害的事件。

本版沿用 v2 的移动网络和蒸馏世界模型权重。改动在游戏内的动作规划器。它按返回速度扩大双飞镖低空回程的碰撞预测范围，允许选择持续 0.48 秒的长跳。这轮没有更新神经网络权重。

两组各自在三个游戏副本中打满 100 场。本轮用新的对局编号；游戏内部随机变化由 Unity 控制。难度为 Attuned，9 格血、0 灵魂开场，骨钉 21 伤，第一只 500 血，第二阶段三只各 750 血。游戏速度设为 1 倍。第 2, 5, 8 场同步读取游戏画面，控制器实测每游戏秒决策 19.25 次，其他对局为 23.68 次。所有这些对局都计入结果。

在已配置的 Windows 项目中双击 [观看飞镖策略.vbs](../../观看飞镖策略.vbs)，可以用 3 号槽从头打一场。启动器会核对当前游戏插件与评估使用的二进制是否相同。
