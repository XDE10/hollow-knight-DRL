# 战斗姐妹本地策略 v1

同一份冻结权重在三个独立游戏实例中完成了 10 场原速、原伤的战斗。全部通过第一只，9 场通关，1 场全程无伤。场均实测伤害 2613.8，地刺掉血合计 0 格。三姐妹本体和飞镖分别打掉 32 和 17 格。逐场成绩在 [evaluation.json](evaluation.json)，预先分配的场次和校验值在 [frozen.json](frozen.json)。

竞技场为战斗姐妹 `GG_Mantis_Lords_V`，难度 Attuned，开局 9 格血、0 灵魂，骨钉伤害 21。开场敌人 500 血，第二阶段三只各 750 血。胜利要求游戏触发竞技场完成事件且骑士存活。每局最多 480 游戏秒，其中 8 场在 180 秒内获胜，另 1 场用时 182.92 秒。种子编号用于区分 Python 调用，Unity 战斗随机性独立。

## 模型

`head.weights` 包含一个 56 → 32 → 12 的移动动作价值网络。17 场开发对局产生 102840 条含左右镜像的数据，600 次梯度更新结合按局部回报加权的模仿损失与 Double DQN 目标。输入包含骑士、最多三只活动本体和两个最近的飞镖。网络给移动、跳跃和冲刺的组合打分。本地预测控制器综合这个分数、未来碰撞、平台边缘和攻击机会，输出普通游戏按键。转向挥刀、施法和聚集由控制器处理。此前的 PPO 检查点另行保存。

两份文本权重可逐字节校验，C# 读取的数值顺序为 PyTorch 两个线性层各自的权重与偏置。复训入口为 `scripts/train_sisters_tactics_head.py`，输入为按原顺序排列的开发对局报告、同名前缀的真实控制记录和逐步轨迹。正式评估的十场均在冻结之后采集。

## 使用

将本项目的 HKRLEnvMod 部署到训练用游戏副本。项目本机配置通过现有的 `scripts/windows/game_runtime.ps1` 提供本地连接参数。游戏必须从启动时载入选定的权重。下面的命令会启动一个可见的游戏窗口，自动打完指定场数并保存逐场成绩。

```powershell
.\scripts\windows\play_sisters_tactics.ps1 -Checkpoint .\models\sisters-tactics-v1 -GameRoot '<已安装本项目 Mod 的训练副本>' -Port 5556 -SaveSlot 4 -Episodes 1
```

该槽需准备好与评估一致的战斗姐妹存档。启动器读取已有存档，准备本地控制文件，并在本次窗口退出后结束。用于训练回放的模型、实体和按键格式见 [ADR-0017](../../docs/adr/0017-sisters-local-tactical-policy.md)。
