# ADR 0022. Use real randomized inputs to refine the frozen Sisters actor

The offline IQL actors use a learned world model during value training. Their estimates for rarely tried actions are sensitive to the teacher and learner trajectories in the replay. The online experiment measures the consequences of two plausible inputs on the actual game PC. This is an optional training stage after the offline policy has learned to clear fights.

During development the opening network plays its usual greedy inputs. In the three-Sister phase the late network occasionally proposes its highest-scoring joint input and the highest-scoring input with a different movement, jump or dash. If their logit gap is at most three, a fair coin chooses the input for one native decision. The unchanged network controls subsequent decisions. Trials are at least 0.72 game seconds apart. The recorder stores the time, both action indices, the draw, its probability and the original logit gap. It verifies the action actually issued. The game runs at original speed and damage with zero teacher-controlled decisions.

For each draw the learner measures rewards in complete observation intervals inside the next 0.60 game seconds. An interval crossing the draw is excluded because its damage could have occurred before the input. The return includes a discounted continuation from the existing world-assisted IQL value network. Terminal states have zero continuation. Whole fights form separate training and holdout sets.

The policy-gradient update uses the logged assignment probability and retains a KL penalty to the parent actor. It fits a low-rank correction to movement logits using the last hidden layer. The correction folds into the existing native action head. Holdout selection estimates the change in return for the greedy policy over the full catalogue and assigns the worst bounded change when the proposed input falls outside the logged pair. Zero correction remains a candidate. These local return estimates guide development. A stronger policy still needs fresh full-game evidence.

Use `HKRL_NATIVE_ONLINE_CHOICES=1` on a timing-development worker with teacher ratio zero. With `HKRL_TACTICS_POLICY` unset, the game runs only the neural policy and the randomized sampler. Its compact tape stores the real input and timing observation at each decision. The manifest marks these fights with `teacher_labels=false`. Their rewards and transitions can train the world and value networks. Only fights with recorded teacher decisions supply imitation targets or teacher-agreement metrics. Older tapes with a shadow teacher keep their observed labels. Collect and pack a separate set of episodes from one frozen behavior checksum. The following command trains on the extracted development archive.

```sh
python scripts/train_sisters_online_choices.py --data online-data --parent parent/world_iql.bin --learner late/learner.pt --output online-candidate
```

Evaluation disables the recorder and randomized choices. The two original-condition acceptance cohorts remain defined in [the acceptance configuration](../../configs/experiments/sisters_acceptance.json).

## Longer interventions on the executed-movement policy

The compound-action experiment starts from the [frozen executed-movement policy](../../models/sisters-native-iql/timing-executed-movement/). A linear risk readout uses its 192 learned features to identify vulnerable trio states. We trained the readout on observed HP drops in the following 0.72 game seconds in 29 development fights. In seven held fights with 5,237 sampled states there were 284 states followed by a drop. It flagged 1,241 states, of which 210 were followed by a drop. Nearby observations can describe the same contact. These are state counts under the recorded behavior. [Readout weights and per-fight counts](../../models/sisters-native-iql/timing-compound-actions/risk.json)

At a flagged state the frozen network proposes its usual joint input and its highest-scoring feasible input from a different jump, dash or downward-cast class. The control arm retains the usual network. The alternative begins with the complete proposed input and keeps its horizontal and jump-hold intent for 0.32 game seconds. The network continues choosing the other keys. Fresh jump, dash and cast pulses after onset may occur only if the underlying network also requests them. Both arms then return to the usual network. A fair coin assigns the arm during collection, with at least 8.4 game seconds between assignments. The recorder saves the two pre-draw scores, risk, propensity, assigned arm and actual native keys. Independent draw seeds and Unity reset seeds are fixed before collection.

The protocol assigns 18 whole games to fitting and six to the holdout. At four and eight game seconds it measures observed boss damage, mask losses and terminal events. Native HP fills the margins between observations. The return includes observed discounted events and missing native mask costs. The advantage readout fits the four-second outcome using known assignment probabilities and cross-fitting by complete training fight. An accepted readout can run the same options with a learned choice at the decision point. The original world-assisted IQL policy continues to score the raw keys. The world model supplies no simulated reward to this selector.
