# ADR 0027. 用实机对局更新战斗姐妹的 PPO 策略

初始策略能独立打过第一只螳螂。三姐妹同时出现时，骑士有时能及时转向，却在随后的跳跃或冲刺过程中失血。为了学到一次操作的完整后果，保留开局策略和三姐妹阶段的原生按键网络，在后者上训练一个选择两种走法的策略头。

每次机会出现时，网络可以保持当前走法，也可以从可执行的原生按键中选一种不同的跳跃、冲刺或下砸操作。第二种操作持续最多 0.32 个游戏秒。两个机会至少相隔 0.90 秒，且只出现在三姐妹阶段、骑士可受伤且冻结风险模型判为高风险时。网络其余时间继续攻击、走位或施法。

在线训练分为三批，每批八场新的实机对局。每一批由当前策略按自己的概率抽样，游戏记录抽签时的概率、两个动作、最终发出的按键和整场结果。每批结束后，PPO 用这批数据做一次更新，再把新的概率交给游戏。训练器逐次重算抽样概率，并核对游戏端的权重摘要和实际按键。整批用于更新，训练局的胜率只描述采样过程。

回报计入实际对敌伤害、按来源记录的骑士失血、地刺以及整场胜负。每格失血只扣一次，能根据血量变化确定的伤害归到对应按键，其余保留在游戏报告伤害的时间段末尾。价值函数使用其余七场的数据来估计本场后续回报，按实际经过的游戏秒折扣，终局后价值为零。奖励、优势估计和截断概率比都可由轨迹重算。[PPO 训练与导出](../../scripts/train_sisters_option_ppo.py)

世界模型在 Colab L4 上学到了选择不同按键后骑士的位置变化，以及随后敌人本体和飞镖的位置。将它的十项预测差异压缩到冻结编码器上，与当前批次的状态特征共同训练 PPO。游戏内使用导出的神经网络。实机评估关闭抽样，记录每场有几次机会、选了几次替代动作、实际改变了多少次原生按键。[世界模型训练和实测](0026-sisters-action-conditioned-motion.md)

第一阶段按全新种子打原速原伤一百场，开局九格血零灵魂，要求至少 98 胜。出现第三场失利即可确定该权重未达标。达到目标后保存权重和逐场记录，再用新的训练局加强对首次掉血的惩罚。第二次验收另用一百场，要求至少 98 胜，其中至少 95 场无伤。[验收配置](../../configs/experiments/sisters_acceptance.json)

训练前，用旧训练集的 12 场原速对局核对奖励。逐场失血合计 108 格，修正后的 PPO 记录与游戏逐场相等。对这 12 场中的 863 次持续按键也核对了实际执行结果。另在同一段 2,548 次原生决策上分别重放始终选择原走法和始终选择替代走法的控制头，两个版本都有 39 次选择机会，后者改变 178 次按键，C# 和 Python 的逐次输出一致。[逐场对账和按键重放](../../models/sisters-native-iql/timing-online-ppo/preflight.json)

从仓库根目录复算一个已采完的批次时，`batch` 指向该批实际使用的抽样头和对应八场轨迹所在目录。

```sh
base=models/sisters-native-iql/timing-executed-movement
world=models/sisters-native-iql/timing-imagined-motion
python scripts/train_sisters_option_ppo.py --data "$batch/rollout.zip" \
  --parent "$base/world_iql.bin" --learner "$base/learner.pt" \
  --sampler "$batch/sampler.bin" --action-world "$world" --output runs/ppo-next
```
