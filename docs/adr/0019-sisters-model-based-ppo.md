# ADR-0019 战斗姐妹课程主线采用世界模型辅助的 PPO

本项目研究一个问题。用实机对局学习短期动力学，在这些预测里训练 actor 和 critic，能否提高策略在真实游戏里的伤害和生存能力？策略直接选择移动、跳跃、冲刺、挥刀、施法和聚集。99 胜版的手写规划器作为单独的工程对照。

## 数据与世界模型

训练复用已冻结的实体编码器 `models/sisters-world-v2/teachers/world-17.pt`。训练和游戏使用同一个编码函数，对螳螂、飞镖等实体做带掩码的注意力聚合，加上骑士观测构成 128 维状态。91 场开发对局按整局固定划分，68 场参与拟合，23 场留出。正式百场评估数据排除在外。

三个不同初始化的动力学网络学习实际按键、持续时间与下一次观测之间的关系，同时预测输出伤害、四类受伤、回血、胜利和死亡事件。学习目标包含真实的单步及连续两步转移。按整局留出数据评估一至五步预测误差，与保持初始状态的预测比较。游戏状态随时间变化，误差改善本身不能证明策略更强。

## 策略如何学习

1. 用真实记录中的按键初始化 actor，用真实事件的折扣回报初始化 critic。保存 `before_rl.pt` 作为策略梯度更新前的对照。
2. 从训练集中的真实状态出发，actor 在 42 个原始按键组合中采样，在同一个拟合动力学成员上连续执行五步。成员分歧扣减预测奖励。玩家动作和后续动作均由当前 actor 选择。
3. critic 对第五步以后的价值提供自举估计。用折扣因子 0.985、λ 为 0.95 的回报计算优势，按 PPO 裁剪目标更新 actor，按价值损失更新 critic。训练保留到初始策略的 KL 约束和真实回报对价值估计的校正。保存 `imagined_ppo.pt`。
4. 把策略载回游戏，采样它自己的动作，记录当时的合法动作、对数概率、价值、实际伤害和终止。按整场划分回报，用这些新采集的轨迹再次更新 PPO，保存 `real_ppo.pt`。正式评估冻结权重，按分布众数选动作，独立从竞技场开头重置。

想象奖励与实机更新使用同一组事件权重。某个控制间隔内击中敌人得 0.6，遭受本体、飞镖或其他伤害扣 2，踩刺扣 3，胜利得 12，死亡扣 10。回血得 0。比赛成绩另行统计游戏记录的实际伤害点数和掉血格数。

## 实机控制与评估

对修正短按键编码后的版本，另固定一个跳过想象更新的对照组。两组共享同一份实体编码器、同一个预训练检查点、奖励和动作集。一组先做 120 轮想象 PPO，再从自己打出的 48 场对局学习；另一组直接从自己打出的 48 场对局学习。两组均每四场更新一次，以独立的新对局评估。完整场次预算相同，实际决策步数随对局长度变化，报告时分别列出。

游戏只执行网络选出的普通按键；Python 进入对局前检查训练副本监听地址、进程身份、原始伤害倍率和原生战术控制器开关。执行端使用游戏提供的合法动作掩码。模型训练使用的完整按键记录允许同一观测间隔内出现变化；策略每次发出一种组合。这是模型预测可能偏离实机行为的一个来源。训练时在想象空间采样，动作的精确可用性仍以实机返回的掩码为准。

比较更新前、想象 PPO、实机 PPO 三个检查点，记录独立对局的过首只、通关、无伤通关、伤害、各来源掉血及每局选择的动作。原速原伤评估开局 9 格血、0 灵魂。Unity 自行产生战斗随机性，Python 种子用于追踪调用。结果随实测写入模型目录。

从仓库根目录执行。GPU 阶段需要原先的开发轨迹包，可用 `scripts/pack_sisters_world_replay.py` 从带实际控制记录和逐场校验文件的开发对局打包。可复用的结果保存在 [课程模型目录](../../models/sisters-course-ac/README.md)。

```bash
python scripts/train_sisters_latent_ac.py --data "$REPLAY" --encoder models/sisters-world-v2/teachers/world-17.pt --output "$NEW_CHECKPOINT_DIR"
python scripts/run_sisters_latent_ac.py --checkpoint "$NEW_CHECKPOINT_DIR/imagined_ppo.pt" --port 5559 --episodes 10 --seed 9211000 --output "$NEW_EVAL_DIR"
```

第二条命令连接已启动的专用 Windows 游戏副本，端口和输出目录可配置。加 `--train --update-every 4` 启用真实对局的 PPO 更新。当前实验的 Colab 只承担批量学习，本地动作循环始终在本机。

复现短按修正版时，在第一条训练命令中额外传入 `--combat-inputs --warm-steps 2800 --updates 120`。该配置将挥刀等瞬时按键按区间内是否发生编码，保留移动和持续按键的时间占比。状态另附最多三只活动本体、两枚飞镖的相对位置等物理量。每批实机 PPO 梯度更新前都会用采集策略重算所选动作的对数概率。实机训练目录保存每批状态、动作、奖励、价值和整局边界，可独立复查更新。

PPO 的裁剪目标参见 [Schulman 等人的原始论文](https://arxiv.org/abs/1707.06347)。
