这些是单次计算短测，Windows/Colab 的 PyTorch 版本不同，不包含游戏渲染、场景重置、网络延迟，不能转换为打赢 Boss 的训练时间。
现阶段建议先跑本地 MLP；如采用 GRU，可继续联调本地游戏/推理 + Colab 批量训练。无需把每个动作发到远程。

可重复检查（在本项目目录的 Windows PowerShell 执行）
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows\check_local.ps1
加上 -Tests 可先跑 Windows 适用测试。该脚本只使用合成观测，不启动游戏。

游戏购买、安装并配置好 HKRLEnvMod 后
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows\check_game.ps1 -Mode Check
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows\check_game.ps1 -Mode Smoke -Task mantis_lords
Check 只检查连接；Smoke 会重置训练场景并执行短暂随机动作，需要已解锁神居的专用训练存档。
框架是 HK Modding API；不要混用 Gemini 给的 BepInEx/JSON 模板。
仓库当前部署文档指定游戏版本 1.5.78.11833；安装时核对 Modding API 兼容性。
